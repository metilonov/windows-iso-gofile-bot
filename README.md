# Windows 11 → Gofile.io → ссылка в Telegram

Готовый проект для **bothost.ru**, Python 3.12. Google Диск и Tmpfiles здесь
не используются. ISO отправляется одним файлом, без разбиения.
Зависимости — только стандартная библиотека Python; pip-пакеты не нужны.

## Что делает бот

1. Получает ссылку на официальный русский Windows 11 x64 с сайта Microsoft.
2. Скачивает ISO на диск хостинга; проверяет полный размер, SHA-256 из таблицы
   Microsoft и наличие структуры ISO9660.
3. Загружает ISO целиком через API **gofile.io**, показывая процент в /status.
4. Повторно вычисляет SHA-256/MD5 отправляемого потока и сверяет размер и MD5,
   возвращённые Gofile. При несовпадении не сообщает об успешной загрузке.
5. Присылает страницу скачивания вида `https://gofile.io/d/...` и SHA-256.

На хостинге нужен диск под ISO плюс 512 МиБ свободно; практически желательно
**12 ГиБ свободно**. В память ISO целиком не загружается: буфер до 1 МиБ.
БотХост должен иметь исходящий HTTPS-доступ к Microsoft, Telegram и Gofile.

## Установка на БотХост

1. Создайте Telegram-бота через официального **@BotFather**, сохраните токен.
2. Создайте проект на **bothost.ru**, загрузите ZIP либо подключите Git.
3. В корне должны лежать `main.py`, `gofile_upload.py`, `requirements.txt`.
4. Главный файл — **main.py**, запуск — **python main.py**, один экземпляр.
   Для собственной Docker-сборки включён Dockerfile с Python 3.12.
5. Задайте переменные окружения:

| Переменная | Что указать |
| --- | --- |
| `BOT_TOKEN` | Токен от @BotFather |
| `OWNER_TELEGRAM_ID` | Ваш числовой Telegram ID |
| `DATA_DIR` | Необязательно; по умолчанию `/app/data/windows-iso` |
| `GOFILE_TOKEN` | Необязательно; API-токен вашего аккаунта на gofile.io |
| `GOFILE_UPLOAD_HOST` | Необязательно; по умолчанию `upload.gofile.io` |
| `ISO_URL` | Необязательно; свежая прямая HTTPS-ссылка ISO от Microsoft |
| `ISO_SHA256` | Обязателен при ISO_URL; SHA-256 именно этого ISO от Microsoft |

Для получения Telegram ID можно сначала запустить бота с одним BOT_TOKEN
и отправить **/myid**, затем задать OWNER_TELEGRAM_ID и перезапустить.
Переменная USER_ID, которую автоматически задаёт БотХост, не заменяет
Telegram ID. Команды загрузки принимаются только от указанного владельца
в личном чате. Бот использует long polling, домен и webhook не требуются.

**Без GOFILE_TOKEN** бот создаёт гостевой аккаунт Gofile и сохраняет его
токен в `DATA_DIR/gofile-account.json`. Повторные загрузки используют тот
же токен. На Linux файл создаётся с правами 0600. Убедитесь, что DATA_DIR
находится в постоянном хранилище вашего тарифа: иначе кэш и гостевой токен
могут потеряться при пересборке контейнера.

**С GOFILE_TOKEN** загрузка идёт в ваш аккаунт Gofile. Токен берётся из
профиля на **gofile.io**, не с похожих доменов. Сохраняйте токены только
в секретных переменных БотХост. Не добавляйте их в Git, архив или чат.

## Команды Telegram

- **/download** — скачать/повторно проверить ISO в кэше, загрузить на Gofile.
- **/status** — этап, объём скачивания или процент отправки.
- **/link** — повторно прислать последнюю сохранённую ссылку и SHA-256.
- **/cancel** — остановить после текущего сетевого запроса/блока данных.
- **/myid** — узнать числовой ID вашего пользователя Telegram.

/link не проверяет, остался ли файл на Gofile. Если он удалён, отправьте
/download для новой загрузки из проверенного кэша. /download всегда создаёт
новую загрузку Gofile; для простого повторения ссылки используйте /link.
Во время одной операции вторую запустить нельзя.

## Как получить ISO на ваш ПК

Откройте полученную страницу **gofile.io**, скачайте ISO **на внутренний диск**,
например D:\Windows11_Russian_x64.iso. Сравните SHA-256 из сообщения бота:

```powershell
Get-FileHash -LiteralPath 'D:\Windows11_Russian_x64.iso' -Algorithm SHA256
```

На страницу Gofile перейдите в обычном браузере: бот выдаёт **страницу
скачивания**, а не платную прямую ссылку. Не требуется скрипт сборки частей.

## Важные ограничения

- Полученная ссылка общедоступна любому, у кого она есть. Бот не включает
  пароль и не устанавливает гарантированный срок хранения. Бесплатное
  хранение, доступность API, скорость и лимиты зависят от политики Gofile.
  Скачайте файл после получения ссылки; не используйте сервис как резервную копию.
- Бот не гарантирует доступность Microsoft с IP-адреса БотХост. Он не меняет
  официальный источник на стороннюю сборку или зеркало.
- Если Microsoft изменил формат страницы/API либо отклонил автоматический
  запрос, получите свежую ссылку **64-bit Download → Russian** на
  https://www.microsoft.com/software-download/windows11 в рабочей сети.
  Задайте её в ISO_URL вместе с соответствующим ISO_SHA256 из таблицы
  Microsoft, перезапустите бота и отправьте /download. Ссылки временные и
  могут зависеть от сети. Если IP хостинга заблокирован, нужен другой маршрут.
- При сетевом обрыве скачивание незавершённого ISO начинается заново.
  Проверенный ISO сохраняется в кэше. Неуспешная отправка на Gofile также
  начинается с начала; автоматических попыток не более трёх.
  Если сервер получил файл, но ответ потерялся, возможна лишняя копия в Gofile.
- Ответы HTTP 429/5xx обрабатываются с задержкой; CAPTCHA не обходится.
  При HTTP 401/403 проверьте свой GOFILE_TOKEN и доступность API. При проблеме
  глобального узла можно выбрать официальный региональный GOFILE_UPLOAD_HOST:
  `upload-eu-par.gofile.io`, `upload-na-phx.gofile.io`, `upload-ap-sgp.gofile.io`,
  `upload-ap-hkg.gofile.io`, `upload-ap-tyo.gofile.io`, `upload-sa-sao.gofile.io`.
  Узел должен быть доступен с хостинга; перенаправления на другие сайты не выполняются.
- Ранее проверенный ISO берётся из кэша. Для другого выпуска укажите новую
  пару ISO_URL/ISO_SHA256 либо удалите только собственный кэш этого бота
  через файловый менеджер хостинга.
- Бот не получает существующую Windows 10 с вашей флешки и не подготавливает
  Ventoy удалённо. USB-диски не меняются, Windows не устанавливается,
  компьютер не перезагружается. Подготовка флешки продолжается отдельно
  после получения и проверки ISO на вашем внутреннем диске.

## Проверка проекта

```powershell
python -m unittest -v
```

Тесты проверяют официальный источник, хеши, неполный ISO, отмену, HTML вместо
образа, multipart-передачу, целостность потока, проверку ответа Gofile и
исключение токенов из результата. Это автономные тесты с имитацией API.
Проверено при подготовке: все 11 тестов прошли; отдельная реальная отправка
тестового текстового файла размером 48 байт на Gofile также прошла, сервер
подтвердил совпадающие размер и MD5. Полный Windows ISO не загружался.
Реальная многогигабайтная загрузка и доставка через Telegram требуют вашего
BOT_TOKEN и доступа к сетям; ими эти тесты не являются.
